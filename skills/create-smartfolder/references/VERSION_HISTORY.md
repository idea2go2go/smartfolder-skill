# Version history — SmartFolder Skill

*Read by the skill on demand; never deposited into a user's folder. This is the package's full
changelog, moved out of `SKILL.md`'s header so it no longer loads on every activation; the header
keeps the current version and a one-line what's-new. The repository `CHANGELOG.md` at
github.com/idea2go2go/smartfolder-skill carries the same story in plain language for the public
channel.*

**v6.5.0 — [260815].** Thread masters for capture-fed folders: a conditional growth-menu row
plus a fictionalized master-and-sidecar exemplar pair, for conversations a recurring capture path
keeps fragmenting — one master plus digest per ongoing exchange (RM-17). The trigger widens so a
plain request to organize a folder reaches the skill, with an explicit offer before any
commitment — look first, then offer the method, never assume; requests with a user-supplied
scheme execute silently, no offer (RM-22). Conditional and historical content moves into this
top-level `references/` folder — read on demand, never deposited — under a standing 550-line
budget for `SKILL.md`, asserted at every release (RM-24). The deposited version check gets a
canonical home: the kit's new `Example_VERSION_BASELINE.md` carries the complete monthly check in
deposited form, and Phase 5 collapses to a deposit instruction (RM-23). The wider trigger is
affordable because the loaded size drops — RM-22 and RM-24 were designed together.

**v6.4.0 — [260813].** Deposited rules now say what happens when the environment differs —
never-delete stated as unconditional policy with its capability parenthetical struck, the drift
matrix attributing removals from evidence rather than from what an actor could have done, a
general deposited-rule principle (a capability may be a condition, never a reason), and a Phase-6
capability-language sweep (RM-11, absorbing IN-5); open the exemplar before authoring the
artifact it models — the kit table is the index, the exemplar the specification of what an
artifact is, never of what yours must be, with the open-the-artifact sentence deposited in the
growth menu (RM-15); session-flags identity established, never assumed — the non-gating
announcement protocol, the register stated targeted-not-private, evidence-basis delivery stamps
(RM-16); the Markdown-reader recommendation hedged — MDHero on Windows, any equivalent works
(RM-18); the SmartFolder outer-name suffix raised in Phase 2 and offered at close-out, with the
reconnect step (RM-20); the version check reads /releases/latest as load-bearing, "you are
current" takes a fetch in this session and better evidence than "something newer exists", two
free tripwires, a repeated-failure sentence, and a repair offer for deposited checks (RM-21); the
Existing SmartFolders path rewritten state-first around the repairs deposits cannot make to
themselves.

**v6.3.0 — [260804].** Close-the-loop hardened — the distant test sweeps the whole surface
inventory, external-state surfaces are distant by definition, point-in-time state moves out of
prescriptive files, and irreducible constants carry source pointers (RM-9); monthly version check
deposited into every built folder — run in ordinary use by any assistant, with a download offer
and an explicit assessment ask (RM-10); boundary duties grouped in one root-file section;
session-flags register for collaborative folders, plus the session-boundary prompt asked of every
folder (RM-12); the staging rule restated as a category, with a light disposal-manifest carve-out
(RM-13); housekeeping folders renamed XX_INBOX and XX_DELETE_MANUALLY, and the generator's
staging guards fixed to match (RM-14).

**v6.2.0 — [260728].** Drift-disposition matrix added to the kit (RM-1); agent-population dial
with guarded CLAUDE.md/AGENTS.md duplication and a Phase-6 parity probe (RM-2); conditional owner
buy-in with owner-letter and owner-guide exemplars (RM-3); growth menu deposited, two axes
(RM-4); version baseline deposited with an upgrade-review procedure (RM-5); write-time
close-the-loop rules (RM-7); developer feedback offer in the growth menu (RM-8); display name
corrected to "SmartFolder Skill"; kit README script count corrected.

**v6.1.1 — [260724].** Kit script sample configuration and docstring examples use invented
placeholder content throughout. No functional change.

**v6.1.** Added the write-forward (state-first) discipline for live surfaces, deposited into each
