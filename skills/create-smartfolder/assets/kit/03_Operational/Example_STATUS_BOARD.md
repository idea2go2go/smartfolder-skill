each ROW carries its own as-of date — the date the underlying status reflects, not the date someone
edited the board — and the RECENCY TIEBREAKER is stated right on the board.)*

initiative + its next gate + links. Each row carries its own "Status as of" date: the most recent

refresh the header snapshot date whenever any row changes. A row that accretes dated narrative gets
that narrative moved to the initiative's README/deal-arc home, then trimmed to the present. **Recency tiebreaker:** if this board and an
initiative README disagree, the more recent as-of date wins — refresh the staler surface. The board
row is the source of truth for the one-line status; the README carries the fuller narrative.
